# Dotfiles

Personal Linux configuration files and setup helpers.

## What's included

- **Kitty** terminal configuration and theme
- **Niri** compositor configuration
- **Zsh** shell configuration and Starship prompt settings
- **VS Code** extension list and setup script for supported VS Code editors

The `sway/` directory is reserved for Sway configuration. Machine-specific files in `local/` are ignored by Git.

## VS Code setup

Run the setup script to install the listed extensions and apply the repository's VS Code setup:

```sh
./vscode-config/setup-vscode.sh
```
